# Dev logs

Mastro records what your app is doing while you develop it: every request
and, for SQLite apps, every query. The lines go to the console and to an
in-process viewer at `/logs`.

## Console output

The format follows `LOG_FORMAT`:

| `LOG_FORMAT` | Output |
|--------------|--------|
| unset | JSON in development, plain text otherwise |
| `json` | One JSON object per line, with a `kind` field |
| `text` | The classic `200 GET /posts (4ms)` line |

```bash
APP_ENV=dev gleam run
# {"kind":"request","method":"GET","path":"/posts","status":200,"duration_ms":4}
# {"kind":"sql","statement":"SELECT id, title FROM posts ORDER BY id DESC","params":0,"duration_ms":1}
```

```bash
LOG_FORMAT=text APP_ENV=dev gleam run
# 200 GET /posts (4ms)
# [sql 1ms, 0 params] SELECT id, title FROM posts ORDER BY id DESC
```

Request lines are written by `dev_log.request_log`, the middleware the
generated router installs. It replaces `wisp.log_request`, so you get one
line per request, not two.

## The `/logs` viewer

```
http://localhost:4000/logs
```

`/logs` shows the most recent 200 entries, newest first, and refreshes every
two seconds. It answers **only in development and only from localhost** — a
request whose `Host` is not `localhost`, `127.0.0.1` or `[::1]` gets a 404.

The entries live in an actor started in `main()`:

```gleam
let logs =
  dev_log.start(200, dev_log.options(config.log_json(cfg), config.is_development(cfg)))
dev_log.install(logs)
```

`install` publishes the store so repository code can call `dev_log.sql`
without you threading it through every function. It is a no-op everywhere
else: the CLI, tests and production all skip it.

## Recording your own SQL

The SQLite repo generated by `mastro new` already routes queries through a
helper that logs them:

```gleam
// src/<app>/data/repo.gleam
pub fn query(
  db_path: String,
  sql: String,
  params: List(sqlight.Value),
  expecting: decode.Decoder(a),
) -> Result(List(a), sqlight.Error) {
  use conn <- sqlight.with_connection(db_path)
  let start = dev_log.now_ms()
  let result = sqlight.query(sql, on: conn, with: params, expecting: expecting)
  dev_log.sql(sql, list.length(params), dev_log.now_ms() - start)
  result
}
```

For a hand-written query, time it the same way:

```gleam
import mastro/dev_log

let start = dev_log.now_ms()
let result = run_my_query()
dev_log.sql("SELECT * FROM reports", 0, dev_log.now_ms() - start)
```

## Boot banner

`main()` picks the port with `net.pick_port(cfg.port, 10)`: when the
preferred port is busy, the dev server takes the next free one instead of
crashing. The banner names the local URL and every LAN address the app is
reachable at, so you can open it on a phone:

```

  my_app dev server
  Local:   http://localhost:4000
  Network: http://192.168.1.20:4000

```

The addresses come from `net.lan_addresses()` and are never concatenated
with `APP_URL` — they are what the interfaces report.
